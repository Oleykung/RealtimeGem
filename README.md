# Granado Espada M - Realtime Boss Tracker

Realtime Sync Discord <-> Web via WebSocket ws://localhost:8080/ws

- Discord พิมพ์ /bosskill แบบ autocomplete พิมพ์ชื่อได้เลย ไม่ต้องเลือกรายชื่อตายตัว
- แก้ไขบอสที่เว็บ -> ส่งไป Discord ทันที via WebSocket
- Kill/Reset ที่ Discord -> เว็บอัปเดตทันที

Run: python bot.py
Web: http://localhost:8080
